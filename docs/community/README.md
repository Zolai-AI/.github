## Interview template (PLANNED — KR5.1)

| Field | Prompt |
|-------|--------|
| Demographics | Age range, location, language use patterns |
| Language background | First language, other languages, Zolai proficiency self-assessment |
| Digital tools | Current tools used for Zolai (if any), unmet needs |
| Learning habits | How they learn/study Zolai, what materials they use |
| Pain points | Biggest frustrations with current Zolai digital resources |
| Feature wishes | What tool would they use daily? What would it do? |
| Consent | Permission to use anonymized feedback in research/publications |

## Consent framework (PLANNED — KR5.2)

Before collecting any community data:

1. **Informed consent form** — plain-language explanation of project, data use, publication plans
2. **Anonymization** — no names in research outputs without explicit permission
3. **Right to withdraw** — participants can withdraw data at any time
4. **Data storage** — interview transcripts stored in `docs/private/` (gitignored)
5. **Publication review** — participants can review quotes before publication

See also: CARE principles in [`../governance/data-governance.md`](../governance/data-governance.md)
