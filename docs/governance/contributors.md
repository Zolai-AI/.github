## Role definitions

| Role | Meaning |
|------|---------|
| Founder | Originates and leads the initiative; final operational decision maker unless delegated |
| Advisor | Provides guidance; no default ownership or veto |
| Research collaborator | Joint research; credit/IP per agreement |
| Developer | Code contributions under project license |
| Linguist | Language/data expertise; attribution required |
| Community contributor | Content, validation, feedback — with consent |
| Reviewer | Peer review of docs/code/data |
| Volunteer | Time contribution without employment |
| Partner organization | Institutional collaboration |
| Future employee | **FUTURE / PLANNED** — does not exist yet |
