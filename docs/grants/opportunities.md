## How to advance a row

1. Open the **official** program page; paste URL  
2. Record eligibility, deadline, amount, geography  
3. Only then move to `potentially eligible` / `eligible`  
4. Link OKRs from [`../strategy/okr.md`](../strategy/okr.md)

## Do not

- List a program as `eligible` from memory  
- Put unverified deadlines in public README or white paper  
- Submit while commercial arrangement / ownership is undefined (if funder requires disclosure)
- Cite Enduring Voices or LINGUA Africa/Europe as Zolai application targets
