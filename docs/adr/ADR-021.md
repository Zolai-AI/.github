## Context and verified audit evidence

The user's expanded scope names shared layers: *ai sdk, ai layer, provider, database, repo,
factory, builder, observer, ui, components* with support across languages and frameworks. The
audit facts below are the authority; this ADR does not invent new ownership.

**Canonical Python already exists (do not re-create it):**

- `zolai-core/zolai/shared/contracts/{base,claim,evidence,hypothesis,lexicon,pattern,source,version}.py`
  hold **11 typed knowledge contracts** plus `KnowledgeStatus` lifecycle and the evidence gate.
  Its `__init__.py` states the single canonical home and that cross-domain imports go through
  `shared`: **types + validation only** — not a second runtime layer.
- Provider system: `zolai-core/zolai/llm/providers/{base,openai,gemini,openrouter,ollama,webapi}.py`,
  `zolai-core/zolai/llm/provider_settings.py`, `zolai-core/zolai/llm/fallback.py`.
- Persistence: `zolai-core/zolai/data/repositories/{base,foundation,observation,provenance,...}.py`
  (`BaseRepository`: transactions, audit, optimistic lock, soft delete),
  `zolai-core/zolai/data/database.py`, `zolai-core/zolai/data/database_layer.py`.
- Engine/AI-mode gate: `zolai-core/zolai/engines.py` — rule/hybrid/AI registry with `llm_allowed`.
- Observer pipeline: `zolai-core/zolai/foundation/observation/*`.
- Tool contracts: `zolai-core/zolai/api/foundation_router.py` exposes **11 typed tool contracts**,
  tested by `zolai-core/tests/test_foundation_contract.py`.
- MCP surface is served by `zolai-core` at `https://mcp.zolai.space/mcp` and `/api/v1/mcp`,
  tiers **8 public / 31 member / 39 admin** ([root AGENTS.md](../../AGENTS.md), ADR-020 §Context).

**TypeScript duplication is real but not uniform:**

- `cn()` in `zolai-web/lib/utils.ts`, `zolai-explorer/src/lib/utils.ts`,
  `zolai-landing/src/lib/utils.ts`; Tauri frontend imports the `cn` package.
- shadcn primitives exist in four separate `components/ui` folders (`zolai-web`,
  `zolai-explorer/src`, `zolai-tauri/frontend/src`, `zolai-landing/src`) and are **not**
  byte-identical: web separator uses `bg-border` + `data-slot`, landing uses `bg-white/10`;
  web input is `h-9`, Tauri input is `h-8`. They are local skins, not shared products.
- landing and journey duplicate feature filenames (`Repos.tsx`, `Hero.tsx`, `Navbar.tsx`,
  `Footer.tsx`, `HeroScene.tsx`) but differ semantically (e.g. `Repos.tsx`
  **5718 vs 2019 bytes**). Share data hooks/contracts, not visual components.
- API clients are structurally similar but framework-bound: `zolai-explorer/src/lib/api.ts`
  (typed fetch, `ApiError` kind union, `X-API-Key`, 15s/65s timeouts),
  `zolai-tauri/frontend/src/lib/zolai-core/client.ts` (single fetch choke point, `ApiError`
  status/detail, base URL from settings), `zolai-web/lib/api/client.ts` (Hono RPC + cookies).
  Provider logic: `zolai-web/lib/ai/providers.ts`, `zolai-web/lib/ai/multi-provider-pool.ts`
  (`MODEL_CONFIGS`, discovery), `zolai-tauri/frontend/src/lib/ai/provider.ts` (OpenAI-compatible
  streaming + `/chat/zolai`), `zolai-tauri/frontend/src/lib/providers.ts` (Provider types).
  React Query defaults: `zolai-web/app/providers.tsx`, `zolai-explorer/src/lib/queryClient.ts`.
- No consumer declares `ai` (Vercel AI SDK) today; web uses Anthropic SDK and other provider
  SDKs; Tauri frontend uses `openai` (all five `package.json` files, ADR-020 §Context).
- Rust is thin: `zolai-tauri/src-tauri/src` has only `main.rs` + `sidecar.rs`; real logic runs in
  Python core through the sidecar. Root has no `package.json`/Bun workspace (ADR-020).

## Framework decision (2026-11-24)

**KEEP Next.js in `zolai-web`; do not migrate it to Vite.** Full sharing works by sharing React 19
packages/contracts/behavior, not by converging frameworks: **Vite-first but Next-compatible** —
explorer/tauri/landing/journey stay Vite; web stays Next.js 16 + Hono + Prisma.

Evidence (verbatim): `zolai-web/AGENTS.md:191` — "`zolai-web` keeps its Next.js + Hono + Prisma architecture. This repo follows the workspace-canonical 7-stage SDLC and document map; no stage gate is skipped."
`zolai-web/AGENTS.md:203-204` — "Stack unchanged: Next.js stays. React + Vite + shadcn/ui patterns are reused where already present." / "Next.js → Vite and React + Vite + API decoupling are **issues only** — not implemented here."

Measured surface: **99 `page.tsx`**, **8 `route.ts`**, **76 `next/link`**, **47 `next/navigation`**,
**22 `next/cache`**, **12 `next/image`**, **10 `next/headers`**, **7 `next/server`**, plus Hono RPC,
Prisma server code, better-auth cookies and a custom VPS deploy script.

Ownership: per-layer owners remain **needs-founder**; **founder is the escalation owner** for any future framework override — no override is made here.

Shared-package compatibility rules:
- No `import.meta.env` or other Vite-only APIs in shared code; base URL/env values injected by the consumer.
- React 19 peer dep; interactive shared components are plain client components, marked `"use client"` at the consuming boundary.
- Avoid RSC-only APIs and `server-only` imports in shared modules; server routes/credentials stay in each app.
- Tailwind 4 tokens shared; themed skins stay local.
- Verify with both a Vite smoke build and a Next.js consumer build (Phase 4a).

## Principle: CONTRACT-FIRST

1. `zolai-core/zolai/shared/contracts` and the `foundation_router` tool contracts are the
   **single source of truth**. Validation and type shape are defined once, in Python.
2. TypeScript and Rust are **generated or deliberately small projections**. Hand-maintained
   parallel schemas are forbidden: a TS interface, Rust struct or JSON Schema snapshot may only
   be emitted from the canonical contract or justified as a local UI-only view type.
3. Runtime authority stays server-side: tier checks (8/31/39), evidence gating, `llm_allowed`,
   transactions/audit, and provider credentials remain in `zolai-core`. Projections carry data
   shapes and tier metadata for UI gating only.

## Factory, builder, observer — definitions and current homes

- **Factory** = construction of providers, clients and engines from configuration. Today:
  `zolai-core/zolai/engines.py` (engine selection under `llm_allowed`),
  `zolai-core/zolai/llm/provider_settings.py` + `providers/*` (provider construction/fallback),
  and per-app client creation in `zolai-explorer/src/lib/api.ts`,
  `zolai-tauri/frontend/src/lib/zolai-core/client.ts`, `zolai-web/lib/api/client.ts`.
  **Rule:** a factory may build only from canonical contracts/generated config; it never defines
  a new tool shape, tier map or provider capability set.
- **Builder** = dataset, prompt and tool-call assembly. Today: dataset work lives in the separate
  `zolai-datasets` repo; prompt/tool-call assembly is driven by `zolai-core/zolai/engines.py` and
  the `foundation_router` tool contracts; `zolai-web/lib/ai/multi-provider-pool.ts` holds local
  model discovery config. **Rule:** builders consume contracts, do not redefine them.
- **Observer** = telemetry, audit and evidence events. Today:
  `zolai-core/zolai/foundation/observation/*` plus `BaseRepository` audit; TS-side projections are
  `ApiError` kinds, query defaults and client request telemetry in the two fetch wrappers.
  **Rule:** evidence/audit authority stays in core; client events are irreversible append-only
  projections, never a second gate.

## DRY policy

**Centralize (generated or one implementation):** knowledge/tool contracts and `ApiError` shape;
provider settings types; HTTP/MCP client with injected `getToken()`; `cn()` helper after the
deletion-safety rule; React Query defaults; design tokens; shared data hooks (e.g. GitHub repos
fetching for landing/journey). No secrets, keys or env reads in shared bundles
([architecture invariants](../../context/architecture.md), [root AGENTS.md](../../AGENTS.md) §Secret Hygiene).

**Keep local:** themed shadcn skins (`bg-border` vs `bg-white/10`, `h-9` vs `h-8`), cinematic
scenes and differing `Hero`/`Repos` implementations, localStorage key handling, Tauri `invoke`
bridge and sidecar spawn, web Hono RPC client + cookies, Prisma application store (not the data
source of truth), provider SDK choices and model lists.

**Deletion safety rule:** before removing duplicated `cn()`/fetch wrappers or any local schema,
produce caller/dependency analysis, characterization tests, and a rollback. "10% add-back" is a
heuristic for judging over-deletion, **not** a quota or permission to skip tests.

## Distribution

- **TypeScript:** standalone `@zolai/ai-kit` repo published to GitHub Packages, local `bun link`,
  as decided in [ADR-020](ADR-020.md). No root Bun workspace restructure or `file:` sibling paths.
- **Python:** stays in `zolai-core` — **no new Python package**; canonical contracts already live
  there and are imported through `shared` (types + validation only).
- **Rust:** stays in `zolai-tauri` until a real third Rust consumer appears; generated structs are
  checked in beside `main.rs`/`sidecar.rs`, not published as a new crate.
- **Generated artifacts are checked in** (TS types/manifest, Rust structs) with CI drift failure;
  generated files are never hand-edited to silence a check.

## Ordered improvement algorithm

1. **Question requirements.** Name an accountable owner for each layer and cite evidence.
   Unknown owner = **needs-founder**; never invent an owner or approval. Mark unverifiable claims
   UNKNOWN and open a decision per [source-of-truth](../governance/source-of-truth.md).
2. **Delete unnecessary parts.** Caller/dependency analysis + tests + rollback **before** removing
   duplicated `cn()`/fetch wrappers or parallel schemas; 10% add-back is a heuristic, not a quota.
3. **Simplify / optimize only what remains.** Measure baseline (bundle size, type-check time,
   API contract count, drift-check runtime) and simplify retained layers against it; re-measure.
4. **Accelerate cycles only after 1–3.** No skipped gates: typecheck, tests, lint, contract drift,
   GitHub Packages auth, secret-hygiene scan.
5. **Automate last.** Only after a proven reversible manual process: bounded authority (least
   privilege `packages:read`, scoped publish identity), audit trail (commit SHA + package version
   in artifacts), and tested rollback (pin previous version).

## Risks / open questions

- No owner is named for any layer; all ownership is **needs-founder**. PROPOSED grants no
  implementation approval: no repo creation, publishing, manifest edits or rollout is authorized.
- GitHub Packages CI auth and cross-repo version pinning are unresolved (ADR-020 §Risks).
- Generated contract churn: Python contract changes must not silently break four consumers; the
  tier counts 8/31/39 and 11/11 contract counts are drift assertions, not formatting preferences.
- Themed components are intentionally non-identical; extracting visual primitives would regress
  local design. Landing/journey components differ in size and intent — data hooks only.
- `ai` (Vercel AI SDK) is absent today; adopting it stays an explicit consumer decision.
- Tauri offline mode and the sidecar bridge remain local; no cloud token may enter the desktop
  bundle; Rust projection stays minimal until a third consumer exists.
- Web Prisma store and canonical `data/zolai.db` are different lanes; do not unify them here.
- `docs/mcp-surface.md` still labels the MCP surface PLANNED while root AGENTS.md records it
  live; reconcile in Phase 2/6, do not treat the stale banner as authority.

## Rejected alternatives

- **Next.js → Vite migration in `zolai-web`** — rejected: recorded alignment says "Stack
  unchanged: Next.js stays" and migration is an **issue only** (`zolai-web/AGENTS.md:203-204`);
  "`zolai-web` keeps its Next.js + Hono + Prisma architecture" (`:191`). Measured surface:
  99 `page.tsx`, 8 `route.ts`, 76 `next/link`, 47 `next/navigation`, 22 `next/cache`,
  12 `next/image`, 10 `next/headers`, 7 `next/server`, plus Hono RPC, Prisma server code,
  better-auth cookies and a custom VPS deploy script. Share React 19 packages instead.
- **Hand-maintained parallel schemas in TS/Rust** — primary failure mode; violates CONTRACT-FIRST.
- **Root Bun workspace restructure / `file:` sibling dependency** — ADR-020 rejected both: no
  root workspace exists; independent CI checkouts and deploy pipelines stay authoritative.
- **New Python package for contracts** — duplicates `zolai/shared/contracts` canonical home.
- **Shared themed shadcn component package** — local skins differ; share tokens/behavior only.
- **New Rust crate now** — Tauri sidecar is thin and has one consumer; keep generated structs local.
- **Template copying as strategy** — retains the duplication; allowed only as rollback.
- **Auto-publish or unattended drift bypass** — forbidden before steps 1–5 and bounded authority.
