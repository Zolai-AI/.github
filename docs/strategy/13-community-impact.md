## Impact Collection Methods

### Automated Metrics (Monthly)
- Database statistics (entries, patterns, exercises)
- Compliance rates (ZVS 2018)
- Server usage (MCP, web app)
- Git activity (commits, contributors)

### Human-Collected Metrics (Quarterly)
- Speaker interviews (5+ per quarter)
- Community feedback sessions (1+ per quarter)
- User surveys (if app launched)
- Partner check-ins

### Story Collection (Ongoing)
- User testimonials (with consent)
- Case studies of language preservation
- Before/after comparisons
- Community voice recordings (with consent)
