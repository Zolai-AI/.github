## Recommended Grant Strategy

### Phase 1: Build Readiness (Months 1-3)
1. Complete all 8 critical requirements
2. Identify 3-5 target grant programs
3. Build relationships with program officers
4. Join relevant networks (AmericasNLP, Masakhane)

### Phase 2: Submit Applications (Months 3-6)
1. Submit 2-3 grant applications
2. Target: UNESCO IDIL, National Geographic, smaller foundations
3. Budget range: $30K-100K per grant
4. Track all applications and outcomes

### Phase 3: Scale Funding (Months 6-12)
1. Apply to larger programs (NSF DLI-DEL if U.S. partner secured)
2. Build track record with small grants
3. Diversify funding sources
4. Explore corporate partnerships

### Phase 4: Sustainable Funding (Year 2+)
1. Combine grant funding with revenue
2. Build collaborative grants with partners
3. Establish recurring funding relationships
4. Create endowment or reserve fund
