## Critical Grammar Rules

### Word Order (SOV)
- Agreement (ka/na/a) ALWAYS comes DIRECTLY before verb
- Adverbs (mahmah) come AFTER verb, BEFORE hi
- Example: `Amaute a siam mahmah hi.`

### Negation
- `kei` = standard negation for ALL persons
- `lo` = literary/formal (standalone, NO agreement)
- Example: `Ka pai kei hi.`

### Questions
- `hiam` = yes/no question at end
- `bang hang` = content question (why/how)
- Example: `Na ne hiam?`

### Tense/Aspect
- `khin` = past simple / experiential
- `ta` = completive/realized aspect (NOT past!)
- `ding` = future
- Example: `A pai khin hi.`

### Pronouns
- `hihte` = they (respectful/older)
- `amaute` = they (standard)
- `huate` = those/them
- `u` = elder brother/sister (NOT "they"!)
- `nau` = younger brother/sister
- `uh` = plural marker (NOT standalone "they")

### Eating Verbs
- `ne` = general eating/drinking
- `nek` = specific/conditional (if you eat that)
- Example: `Na ne hiam?` NOT `Na nek hiam?`

### Work Nouns
- `nasep` = work/service
- `kammal` = deed/action/commandment
- Example: `Nasep a mankhin ta hi.`

### Tree vs Wood
- `sing` = wood (material)
- `singkung` = tree (living plant)

### Verb: lasak
- `lasak` = sing/song OR take something
- Context determines meaning
