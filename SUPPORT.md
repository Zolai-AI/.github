# Support — Zolai-AI

## Get help

- Report bugs or request features via GitHub Issues on the relevant repo.
- For org-wide questions, open an issue on [Zolai-AI/.github](https://github.com/Zolai-AI/.github).
- Security vulnerabilities: see [SECURITY.md](community/SECURITY.md).

## Supported languages

The Zolai project focuses on Tedim Chin / Zolai (ISO 639-3: ctd), ZVS 2018 standard.
Contributions and questions in English or Zolai are welcome.
