This is the **public org profile** repository for [Zolai-AI](https://github.com/Zolai-AI).
Its `profile/README.md` renders on the org Overview page. This is not a code repo.

- `logo.png` / `og.png` — brand assets (original website logo)
- `community/` — CONTRIBUTING.md, SECURITY.md
- `.github/workflows/lint.yml` — org-level lint (ruff)

Profile repo + community standards. No application code, no API, no tests.
